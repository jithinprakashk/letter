# Malayalam Love Letter Book ❤️

This is a mobile-first Malayalam digital love-letter book with swipe page turning.

## Files
- `index.html` — complete letter and page structure (now with a photo memories page)
- `style.css` — book design and responsive mobile styling
- `script.js` — page turning, swipe controls, and real background music
- `1.jpg`, `2.jpg`, `3.jpg` — the three photos shown on the "ഓർമ്മകൾ" (Memories) page
- `music.m4a` — background music, played/paused with the ♪ button in the top bar

## GitHub Pages
Create a repository, upload **all** the files above (not just the three original ones), then:
**Settings → Pages → Deploy from a branch → main → /(root) → Save**

Your public address will be similar to:
`https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

Note: mobile browsers block audio from autoplaying, so the music starts only after she taps the ♪ button — that's expected, not a bug.

The site uses Google Fonts for Noto Serif Malayalam when internet access is available.
